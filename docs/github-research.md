# GitHub search: 2026-10-07

The [original Workshop page](https://steamcommunity.com/sharedfiles/filedetails/?id=3747745835) names Afyrmo and links its discussion and companion mods, but no GitHub project.

Official GitHub API searches for `MoodleEffectsExplained` and `"Moodle Effects Explained"` returned zero repositories. The public [Afyrmo account](https://github.com/Afyrmo) reports `public_repos: 0`; the repository-list endpoint was empty. That account contains no public name, bio or website linking it to the Steam author, so matching handles alone do not establish identity.

This establishes that no reviewable public upstream project was found by these searches. It does not rule out a private repository or another account name. The proposal therefore uses an independently labelled repository under `antikristianos`, instead of inventing an upstream fork or PR target.
